# FlameScope answer server

Live version of [FlameScope](https://github.com/md-zaid-10/Flame-in-Freefall-by-Cosmic-Outliers)
(NASA Space Apps 2026, team Cosmic Outliers). It searches NASA's microgravity combustion
archive and answers new questions with a Groq-hosted LLM. This Space is deployed
automatically from the GitHub repository; edit the code there, not here.
